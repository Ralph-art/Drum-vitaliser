# Drum Vitaliser - MIDI Drum Generator voor Reaper

Een Python-based tool om drum patterns te genereren gebaseerd op bestaande MIDI-bestanden. Werkt binnen Reaper via ReaScript.

## 🎯 Kenmerken

- **MIDI Analyse**: Extracteer drum patterns, tempo en maatstructuur uit bestaande MIDI-bestanden
- **Pattern Generatie**: Genereer nieuwe drum patterns gebaseerd op geanalyseerde patronen
- **Variatie**: Voeg variatie toe aan bestaande patterns
- **Reaper Integratie**: Directe integratie met Reaper via ReaScript
- **CLI Interface**: Gebruik via command line

## 🚀 Installatie

### Vereisten

- Python 3.8 of hoger
- Reaper geïnstalleerd op Linux Ubuntu
- pip (Python package manager)
